# 📢 Complaint Management Portal

A responsive web application for managing complaints, tracking tickets, live chat support, and admin analytics.  
Built with **HTML, CSS, and JavaScript**.

---

## 🚀 Features

- **Online Complaint Submission**  
  Users can submit complaints via a simple form with file upload support.

- **Real-Time Ticket Tracking**  
  Track complaints using Ticket ID, Email, or Name.

- **Admin Dashboard**  
  Admins can log in, filter, and manage complaints.

- **Analytics Dashboard**  
  Visualize complaint trends with charts (powered by Chart.js).

- **Live Support Chat**  
  Interactive chat interface for quick help.

- **Email Notifications**  
  Users receive updates about complaint progress.

---

## 🖼️ Screens & Sections

- **Home Page**: Overview, features, stats, and benefits.  
- **Submit Complaint**: Form with validation and file upload.  
- **Track Ticket**: Search complaints by ID, email, or name.  
- **Live Support**: Chat interface with quick options.  
- **Analytics**: Complaint statistics and charts.  
- **Admin Panel**: Login, ticket management, and filters.

---
